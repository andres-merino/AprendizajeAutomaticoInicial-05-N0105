\section*{Cierre}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\paragraph{Verificación de aprendizaje:} 
\begin{enumerate}[leftmargin=*]
    \item Al reducir cuatro características a dos componentes con PCA, ¿qué información revisarías para decidir si la representación es suficiente?
    
    \item ¿Qué diferencia hay entre conservar dos atributos originales y construir dos componentes principales?
    
    \item Si conservas menos valores singulares al reconstruir una matriz, ¿qué esperas que ocurra con la información representada?

    \item En el ejemplo de preferencias, ¿qué representan $U$, $\Sigma$ y $V^T$?
\end{enumerate}

\paragraph{Preguntas tipo entrevista:} 
\begin{enumerate}[leftmargin=*]
    \item Tienes un dataset con 1000 características y solo 100 muestras. ¿Por qué esto es problemático y cómo usarías PCA para abordarlo? ¿Cuántos componentes principales deberías retener?
    
    \item Si PCA reduce las dimensiones de mi dataset de 100 a 10 características, ¿significa que las 90 características descartadas no eran importantes?
\end{enumerate}

    \item ¿Qué precaución tomarías antes de aplicar e interpretar PCA sobre variables categóricas codificadas como números?
    \item ¿Cómo cambia la aproximación de una matriz de preferencias al conservar uno, dos o más valores singulares?
\end{enumerate}
