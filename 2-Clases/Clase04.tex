\subsection*{Actividad 1: El flujo de trabajo del aprendizaje supervisado}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

Esta actividad presenta los elementos fundamentales del flujo de trabajo: generación de datos, separación en conjuntos, entrenamiento y evaluación. Se desarrollará mediante clase magistral apoyada con ejemplos y discusión guiada.

\paragraph{¿Cómo lo haremos?}
\begin{itemize}[leftmargin=*]
\item \textbf{Presentación del flujo:} Se revisarán las etapas: definición del problema, elección de características y objetivo, división de los datos, preparación cuando sea necesaria, entrenamiento, predicción y evaluación.
\item \textbf{Alcance del ejemplo:} La regresión lineal se usará para recorrer el flujo completo, sin desarrollar aquí su teoría. Entrenar significa estimar sus coeficientes con datos de entrenamiento; prueba permite observar el error en datos separados. Si se comparan alternativas para elegir una, se necesita validación y se reserva prueba para la evaluación final.
\item \textbf{Discusión guiada:} Se plantearán preguntas para reflexionar sobre la importancia de cada etapa.

\end{itemize}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection*{Actividad 2: Implementación en Python de un modelo de regresión lineal}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

La actividad se desarrollará mediante trabajo práctico guiado en Python, utilizando un conjunto de datos simulado.

\paragraph{¿Cómo lo haremos?}
\begin{itemize}[leftmargin=*]
\item \textbf{Implementación en Python:} Los estudiantes accederán a un cuaderno de Jupyter previamente preparado.
\begin{quote}
Enlace al cuaderno: \href{https://colab.research.google.com/github/andres-merino/AprendizajeAutomaticoInicial-05-N0105/blob/main/2-Notebooks/04-Mi-primer-modelo.ipynb}{04-Mi-primer-modelo.ipynb}.
\end{quote}
\item \textbf{Entrenamiento y evaluación:} Identificar qué datos recibe \texttt{fit}, obtener predicciones con \texttt{predict} y calcular el error cuadrático medio (MSE) en prueba. Interpretarlo en unidades cuadradas de la variable objetivo, sin asumir que un valor aislado permite declarar que el modelo es bueno.
\item \textbf{Experimentación:}
\begin{itemize}
    \item Cambiar la proporción de prueba manteniendo fija la semilla y registrar tamaños y MSE en una tabla; explicar que también cambian las observaciones evaluadas y que el conjunto simulado es pequeño.
    \item Explicar por qué no se debe elegir la partición o la semilla que produzca el menor error de prueba.
\end{itemize}
\end{itemize}

\subsection*{Actividad 3: Taller de implementación}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

Los estudiantes iniciarán un modelo de regresión lineal usando scikit-learn, siguiendo los pasos aprendidos, sobre el conjunto de datos \texttt{kingCountyHouseData}. La práctica se completará como tarea y se retomará en el taller de implementación previsto en el cronograma.

\paragraph{¿Cómo lo haremos?}
\begin{itemize}[leftmargin=*]
    \item \textbf{Desarrollo del taller:} Predecir \texttt{price} a partir de \texttt{bedrooms}, \texttt{bathrooms}, \texttt{sqft\_living}, \texttt{sqft\_lot} y \texttt{floors}, documentando la fuente y revisando tipos y faltantes. Separar los datos antes de ajustar cualquier transformación y usar la siguiente plantilla:
    \begin{quote}
    Enlace al cuaderno: \href{https://colab.research.google.com/github/andres-merino/AprendizajeAutomaticoInicial-05-N0105/blob/main/2-Ejercicios/01-Mi-segundo-modelo-Plantilla.ipynb}{01-Mi-segundo-modelo-Plantilla.ipynb}.

    \item \textbf{Evidencia del taller:} Preparar una primera versión del notebook con características y objetivo, dimensiones de las particiones, modelo ajustado, tabla de valores reales y predichos y una interpretación breve del MSE.
    \item \textbf{Soporte y guía:} El instructor revisará la secuencia de trabajo y las decisiones documentadas; no se exige probar transformaciones no vistas en clase.
\end{itemize}
