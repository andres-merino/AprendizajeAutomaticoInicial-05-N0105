\section{Indicaciones}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{itemize}[leftmargin=*]
\item 
    En esta actividad se evalúa si el estudiante \textit{(Criterio 1.3) explica los métodos de aprendizaje supervisado, sus características, aplicaciones, alcance y limitaciones.}
\item
    La exposición se centrará en un modelo supervisado distinto de los estudiados en clase o en una variante nueva de uno de ellos.
\item 
    El estudiante deberá elaborar diapositivas profesionales y grabar un video presentándolas, con el rostro visible durante toda la exposición.
\item 
    En la presentación se deberá incluir el uso de código en \texttt{Python} para la aplicación del método seleccionado, junto con la explicación de los fragmentos más relevantes.
\item 
    La duración de referencia del video será de 6 minutos, con una tolerancia de $\pm$ 90 segundos (entre 4:30 y 7:30), según los niveles de la rúbrica.
\end{itemize}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{Descripción}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

\begin{enumerate}[leftmargin=*]
    \item \textbf{Elección del modelo.} Justificar la elección para un problema concreto. Si se presenta una variante, identificar el modelo de partida, explicar qué cambia en su formulación, entrenamiento o forma de predecir y qué efecto tiene ese cambio. Variar únicamente los valores numéricos de los hiperparámetros corresponde al ajuste del modelo de partida.

    \item \textbf{Elaboración de diapositivas:}
    \begin{itemize}
        \item Crear una presentación profesional sobre el aprendizaje supervisado (¿qué es?).
        \item Explicar cómo funciona el modelo elegido y presentar sus características, aplicaciones, alcance y limitaciones.
        \item Explicar la función de los hiperparámetros relevantes y cómo afectan el comportamiento del modelo.
    \end{itemize}

    \item \textbf{Uso de código en Python:}
    \begin{itemize}
        \item Mostrar código en Python para la aplicación del algoritmo.
        \item Explicar los componentes principales del código (modelo, hiperparámetros y entrenamiento). Si se presenta una variante, señalar dónde se implementa el cambio.
    \end{itemize}

    \item \textbf{Grabación del video:}
    \begin{itemize}
        \item El estudiante deberá grabarse presentando las diapositivas.
        \item El rostro debe ser visible durante toda la exposición.
        \item No se permite únicamente voz en off.
    \end{itemize}

    \item \textbf{Estructura mínima:}
    \begin{itemize}
        \item \textbf{Introducción:} concepto general de aprendizaje supervisado.
        \item \textbf{Desarrollo:} explicación del método, hiperparámetros y código.
        \item \textbf{Cierre:} alcance y limitaciones.
    \end{itemize}

    \item \textbf{Entrega:}
    \begin{itemize}
        \item Subir al aula virtual el enlace (OneDrive) del video.
        \item Respetar el rango de duración establecido y consultar los intervalos de la rúbrica.
    \end{itemize}
\end{enumerate}
